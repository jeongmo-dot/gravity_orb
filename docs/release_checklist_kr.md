# Gravity Orb — 한국 모바일 출시 체크리스트

- 작성: 2026-10-11 (Claude). 사용자 요청: "한국 모바일 버전 게임 출시를 위해서 필요한 기술적 법적 절차 목록"
- 기준: 작성 시점에 확인한 법령·스토어 정책. **법률·세무 자문이 아니다.** `(확인 필요)` 항목은 관할 시·군·구청, 게임물관리위원회(GRAC), 세무사에게 확인한 뒤 결과를 이 문서에 적는다
- 표기: `[ ]` 미완료 · `[x]` 완료 · 담당 = 사용자 / Claude / Codex
- 관련: BM 논의 (2026-10-11 대화) — 판을 바꾸는 유료 아이템은 빼고 "오늘의 도전 + 랭킹"을 중심으로 두는 안을 제안함. 아직 결정 전

## 0. 먼저 정할 것 (사용자)

- [ ] **출시 플랫폼 순서**: Google Play 먼저 / iOS 동시. iOS는 Mac이 있어야 빌드할 수 있다 (§3.3)
- [ ] **BM**: 무료 + 광고 + 광고 제거 1회 결제 / 유료 판매 / 꾸미기 아이템. BM에 따라 §1의 통신판매업·인앱결제 고지·개인정보 범위와 §3.5 플러그인이 달라진다
- [ ] **출시 국가**: 한국만 / 전 세계. 해외에 내면 유럽 개인정보 동의(광고), 나라별 등급 등이 추가된다

## 3. 기술 — 엔진·빌드

### 3.1 엔진
- [ ] 지금 엔진은 **4.8-dev3 개발판**이다. 출시 빌드는 **정식(stable)판**으로 만든다. 4.8 정식이 나오면 그 버전으로, 아니면 최신 정식판으로 내리고 회귀 테스트·물리 해시를 다시 확인한다 (Claude 명세 → Codex)
- [ ] 내보내기 템플릿: 지금은 Windows용만 설치돼 있다 (`%APPDATA%\Godot\export_templates\4.8.dev3`). Android·iOS 템플릿을 설치한다. 정식판으로 바꾸면 그 버전의 템플릿을 받는다

### 3.2 Android
- [ ] JDK 17, Android SDK (Android Studio로 설치), Godot 편집기 설정에 경로 지정
- [ ] **출시 서명 키(keystore)**: 만들고 **안전한 곳에 백업** (잃으면 업데이트를 낼 수 없다). Play 앱 서명 사용
- [ ] AAB로 내보내기, arm64
- [ ] **target API 36 (Android 16) 이상**: 2026-08-31부터 새 앱·업데이트의 요건이다. 해마다 8월에 올라간다
- [ ] 권한 최소화 (진동만 쓰면 진동 권한만)
- [ ] 버전 규칙: versionName은 `project.godot` 버전 (설계서 §10.5.1), versionCode는 빌드마다 늘어나는 정수

### 3.3 iOS
- [ ] **Mac + Xcode가 필요하다.** Windows에서는 iOS를 빌드할 수 없다 → Mac을 준비하거나 클라우드 Mac 빌드를 쓴다
- [ ] 인증서·프로비저닝 프로필, Godot iOS 내보내기
- [ ] 개인정보 매니페스트 (SDK를 넣을 때), 광고 추적을 하면 앱 추적 투명성(ATT) 동의 팝업

### 3.4 개인정보·지원 페이지 호스팅
- [ ] 개인정보 처리방침과 지원 연락처 페이지를 올릴 곳 (예: GitHub Pages). 광고를 넣으면 같은 도메인에 `app-ads.txt`

### 3.5 BM에 따라 추가 (§0 결정 후)
- [ ] 광고: AdMob 계정, Godot 광고 플러그인, 판과 판 사이 노출 규칙 (게임 도중 금지, BLITZ는 몇 판마다), 해외 출시 시 동의 화면
- [ ] 결제: Google Play Billing·StoreKit 플러그인, 구매 복원, §1.7 고지
- [ ] 랭킹·오늘의 도전: Google Play Games·Game Center 리더보드 (자체 서버 없이 시작), 하루 시드

## 4. 모바일 대응 — M10 인박스 후보 (Claude 명세 → Codex)

사용자가 시작을 정하면 아래를 인박스 항목으로 나눈다.
1. **엔진 정식판 전환** (§3.1): 회귀·물리 해시·캡처 동일
2. **Android 빌드 파이프라인**: 내보내기 프리셋, 서명(키는 저장소 밖), AAB, target API 36, `tools/build_android.ps1`, 실제 기기 설치·스모크
3. **터치 조작**: 스와이프 인식 거리·방향 판정을 휴대전화 크기로 다시 맞춤, 실수 입력 측정
4. **성능**: 저사양·중간 사양 Android 기기에서 Jolt 3D + V4 연출 프레임 예산 (p99, 발열·배터리), 필요하면 연출 품질 단계
5. **앱 생명주기**: 백그라운드로 갈 때 일시정지·저장, 돌아오면 재개, 뒤로가기 버튼, 오디오 포커스, 화면 꺼짐 방지
6. **안전 영역·노치**: V3의 안전 영역 처리를 실제 기기에서 확인
7. **라이선스 화면** (§1.10), 필요하면 **등급 표시** (§1.4)
