# 기획서 초안 — 가칭 「그래비티 오브」

> 버전 0.8 · 프로토타입 검증용 기획서
> 0.2 변경 (2026-09-28): 신규 구체를 **스와이프 순간** 생성, 게임오버 조건 재설계 보류
> 0.3 변경 (2026-09-29): 턴 종료에 완전 정지를 요구하지 않음 — **최대 1.5초** 후 입력 재개
> 0.4 변경 (2026-09-29): 새로 생긴 구체는 겹침이 풀릴 때까지 다른 구체를 **잠깐 통과**한다
> 0.4.1 (2026-09-30): 상극 소멸 기본 규칙을 **B안(같은 레벨일 때만 소멸)** 으로 결정
> 0.4.2 (2026-09-30): 반지름을 공식 대신 **레벨별 표**로 확정 (작은 레벨 크기 차이 강조)
> 0.5 (2026-10-01): 노랑 추가(4색), 턴당 생성 수 증가, 미리보기는 다음 턴 묶음 전부 — 공간 압박이 약했다
> 0.6 (2026-10-01): **노랑은 상극 없음**(측정: 상극을 주면 판이 덜 참), **턴당 2개 생성**, **게임오버 = 그 방향으로 더 들어오지 못하면** (생성된 구체가 턴이 끝날 때까지 자리를 못 찾음)
> 0.8 (2026-10-03): **콤보 = 한 턴의 모든 합체·소멸 수** (색·인과 무관), **무게감 강화** (질량 ↑, 큰 구체일수록 빠르게 낙하) — 플레이테스트: 무게 차이가 안 느껴지고 콤보가 너무 안 쌓인다
> 0.7 (2026-10-03): **표현을 3D로** — 입체 구슬, 스와이프 시 보드가 기울어지는 연출. 게임 평면·규칙은 2D 그대로 (물리는 3D 엔진에서 평면 고정)
> 0.6.2 (2026-10-02): **L5~L7 반지름 축소** (115/150/190 → 100/120/140) — 큰 구체가 벽에 쐐기처럼 박혀 판이 굳었다 (#17 측정: L7 86%가 턴 동안 거의 안 움직임)
> 0.6.1 (2026-10-01): 뽑힌 위치가 막혔으면 생성 벽을 따라 **가장 가까운 빈자리**로 비켜 들어온다. 빈자리가 없으면 **입구에서 대기**하고, 턴 끝까지 입구가 안 열리면 게임오버 — 0.6 판정(유령이 바닥 더미에 박힘)은 판이 비어도 평균 13턴에 끝났다
> 모든 수치와 규칙은 가안이며, 플레이테스트 후 조정한다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 턴제 물리 퍼즐 (합체형) |
| 플랫폼 | 모바일 (세로 화면) |
| 입력 | 상하좌우 스와이프 |
| 레퍼런스 | 2048 (4방향 전체 밀기), 수박게임 (물리 기반 구체 합체·성장), 테트리스 (낙하·공간 관리) |
| 한 줄 소개 | 스와이프로 보드의 중력 방향을 바꿔, 같은 색 구체는 키우고 상극 색 구체는 부딪혀 없애는 퍼즐 |

### 차별점
- **수박게임과 달리** 떨어질 위치가 아니라 **중력 방향 자체**를 조작한다.
- **2048과 달리** 격자가 아닌 물리 공간이라 구체가 실제로 커지며 공간을 차지한다.
- **색 충돌 규칙**으로 "키울 것인가, 없앨 것인가"의 선택이 생긴다.

## 2. 핵심 재미 (검증 목표)

프로토타입은 아래 세 가지가 재미있는지만 검증한다.

1. **기울이기의 손맛** — 스와이프 한 번에 보드 전체가 쏟아지는 느낌
2. **성장의 딜레마** — 크게 키울수록 점수는 높지만 공간이 줄어든다
3. **콤보의 쾌감** — 한 번의 스와이프로 합체·소멸이 연달아 터지도록 설계하는 재미 (0.8: 반응끼리 인과가 없어도 같은 턴이면 콤보)

## 3. 게임 규칙

### 3.1 보드
- 정사각형 보드 (4방향 중력이 모두 공평하도록)
- 네 면 모두 벽. 구체는 보드 밖으로 나가지 않는다.
- 게임 시작 시 중력 방향은 **아래**, 구체 2개가 배치된 상태로 시작.

### 3.2 입력
| 입력 | 결과 |
|---|---|
| 위/아래/왼쪽/오른쪽 스와이프 | 해당 방향으로 중력 전환 |
| 현재 중력과 같은 방향 스와이프 | 유효 입력으로 인정 (턴 소모, 신규 구체 생성) |
| 처리 중 입력 | 무시 (입력 잠금) |

- 스와이프 판정: 최소 이동 거리 이상 + 주 방향 성분이 우세할 때 인정
- 같은 방향 반복을 허용할지는 **미정 사항**(7장) 참고

### 3.3 중력
- 스와이프한 방향으로 중력이 **유지**된다. (보드를 기울여 둔 상태)
- 다음 스와이프 전까지 중력 방향은 바뀌지 않는다.

### 3.4 구체
- 속성: **색**, **레벨**
- 레벨이 오를수록 반지름이 커진다.
- 반지름은 **레벨별 표**로 정한다 (0.4.2). 0.4.1까지의 공식 `r = 50 × 1.25^(레벨-1)`은 L1~L3 크기 차이가 눈에 잘 띄지 않았다
- 단위: 기준 해상도 px, 보드 한 변 960px

| 레벨 | 반지름 | 직전 대비 | 지름 / 보드 폭 | 기본 점수 |
|---|---:|---:|---:|---:|
| 1 | 25 | — | 50 / 5% | 2 |
| 2 | 40 | ×1.60 | 80 / 8% | 4 |
| 3 | 60 | ×1.50 | 120 / 13% | 8 |
| 4 | 85 | ×1.42 | 170 / 18% | 16 |
| 5 | 100 | ×1.18 | 200 / 21% | 32 |
| 6 | 120 | ×1.20 | 240 / 25% | 64 |
| 7 (최대) | 140 | ×1.17 | 280 / 29% | 128 |

- 0.6.2에서 L5~L7을 115/150/190에서 줄였다. 큰 구체끼리는 크기 차이가 작아지므로 레벨은 문양·표시로 보완한다 (M8)

- 최대 레벨 구체끼리 합체하면 **둘 다 소멸 + 대량 보너스** (보드 청소 수단)

### 3.5 색 충돌 규칙 (0.5: 4색)

색: **빨강, 파랑, 초록, 노랑**

| 충돌 조합 | 결과 |
|---|---|
| 같은 색 + 같은 레벨 | **합체** → 레벨 +1 구체 1개, 두 구체의 중간 지점에 생성 |
| 같은 색 + 다른 레벨 | 아무 일 없음 (밀고 튕김) |
| 빨강 ↔ 파랑 (상극) | **소멸** → 규칙에 따라 제거 |
| 그 외 조합 | 아무 일 없음 |

- 상극 소멸 규칙 대안(검증 후 선택)
  - A안: 레벨 무관 둘 다 소멸 (판이 거의 차지 않아 공간 압박이 약했다 — 120턴 후 잔여 평균 3.3개)
  - B안: 레벨이 같을 때만 소멸 ← **채택 (2026-09-30 플레이테스트)**. 120턴 후 잔여 평균 5.8개
  - C안: 큰 쪽이 레벨 차이만큼 남음
- **초록·노랑은 상극이 없다** — 없애기 어렵고 안정적으로 키우는 색. 빨강·파랑은 상극으로 없앨 수 있는 색
- 0.5에서 초록↔노랑을 상극으로 시험했으나 소멸 수단이 늘어 판이 오히려 덜 찼다 (180턴 측정). 0.6에서 철회
- 같은 색끼리 만날 확률이 3색 33% → 4색 25%로 줄어 판에 공이 더 오래 남는다

### 3.6 구체 생성
- 매 턴, **스와이프와 동시에** 새 중력의 **반대편 벽**에서 신규 구체 **2개**(0.6, 180턴 측정으로 결정)가 들어와 함께 떨어진다. 각 구체 위치는 독립적으로 무작위
- 생성 위치: 반대편 벽을 따라 무작위 위치를 뽑는다. 그 자리가 기존 구체와 겹치면 **벽을 따라 가장 가까운 빈자리**로 옮겨 생성한다 (0.6.1)
- 생성 벽에 빈자리가 전혀 없으면 구체는 **입구(생성 벽)에서 멈춰 대기**한다. 더미가 새 중력으로 떠나 자리가 나면 그때 들어온다
- 새로 생긴 구체(스와이프 생성·합체 결과)는 다른 구체와 겹쳐 있는 동안 **서로 통과하는 반투명 상태**로 벽에만 부딪히며 떨어지고, 겹침이 풀리면 정상 충돌로 돌아온다. 겹친 채 억지로 밀어내면 이웃이 벽에 박히거나 물리가 폭주하기 때문이다
- 생성 구체: 레벨 1 (90%), 레벨 2 (10%)
- 색: 4색 균등 확률
- **다음 턴에 들어올 구체 묶음(N개) 전부**를 미리보기로 표시

## 4. 턴 처리 순서

```
1. 입력 대기
2. 스와이프 인식 → 입력 잠금
3. 중력 방향 전환 + 반대편 벽에서 신규 구체 생성
4. 물리 시뮬레이션 진행
5. 충돌 발생 시 색 규칙 판정 → 합체/소멸 처리
6. 연쇄 판정: 합체·소멸 후 다시 4번으로 (안정될 때까지 반복)
7. 턴 종료: 모든 구체가 멈추거나(임계값 이하 일정 시간 유지) **최대 1.5초**가 지나면 종료. 남은 움직임은 다음 턴까지 이어진다
8. 게임오버 판정: 이번 턴 생성 구체가 아직 겹침을 못 풀었으면 게임오버 (5.1)
9. 입력 잠금 해제 → 1번으로
```

- 신규 구체가 기울이기와 함께 쏟아지도록 생성을 턴 시작으로 당겼다 (0.1은 안정 후 생성이라 공이 늦게 들어왔다)
- 7번: 0.2까지는 완전 정지를 기다렸으나(최대 3초), 물리 엔진에 구름 저항이 없어 대부분의 턴이 3초를 채웠다. 0.3부터는 **최대 1.5초**로 끊고 굴러가는 구체는 그대로 둔다 (수박게임처럼 멈춤을 기다리지 않음)
- 입력 재개 후에도 합체·소멸은 계속 일어난다. 이 반응은 직전 턴의 연쇄로 이어서 센다
- 연쇄 한 번마다 짧은 히트스톱·이펙트로 "몇 연쇄인지" 읽히게 한다.

## 5. 게임오버 · 점수

### 5.1 게임오버
- **그 방향으로 더 들어오지 못하면 게임오버** (0.6.1): 스와이프로 생성된 구체가 생성 벽에 빈자리가 없어 **입구에서 대기**하다가, **턴이 끝날 때까지 들어오지 못하면** 그 방향은 꽉 찬 것이다
  - 스와이프 순간이 아니라 턴 끝에 판정한다 — 생성 벽에 쌓여 있던 더미가 새 중력으로 떠날 시간을 준다
  - 합체·소멸로 생긴 구체는 판정에서 제외한다 (더미 속에서 생기므로)
  - 방향 경고와 실제 판정은 같은 기준(생성 벽 빈자리)을 쓴다
- **방향 경고**: 턴이 끝날 때 네 벽 각각에 대해 "다음 턴 생성 구체가 들어갈 빈자리가 있는지"를 계산해, 자리가 없는 벽을 붉게 표시한다. 플레이어는 그 방향 스와이프를 피할 수 있다
- 근거: 판 전체가 아니라 **방향별**로 막히므로 "어느 쪽으로 기울일까"라는 판단이 생긴다. 판이 꽉 끼는 구간(점유율 60~70%)에서 물리 엔진이 불안정해지는데, 그 전에 막히는 방향이 생겨 게임이 끝난다

### 5.2 점수
| 항목 | 점수 |
|---|---|
| 합체 | 생성된 구체의 기본 점수 |
| 상극 소멸 | (두 구체 기본 점수 합) × 0.5 |
| 최대 레벨 합체 | 기본 점수 × 5 |
| 콤보 배수 | 한 턴의 n번째 반응(합체·소멸) 점수 × n |

- 표시 지표: 현재 점수, 최고 점수, 최대 콤보
- **콤보 (0.8)**: 스와이프부터 다음 스와이프 전까지 일어난 합체·소멸을 색·인과와 무관하게 모두 센다. 0.7까지의 "합체 결과가 다시 반응해야 연쇄" 조건은 너무 엄격해 콤보가 거의 쌓이지 않았다

## 6. UI · UX

### 6.1 화면 구성 (세로)
```
┌─────────────────┐
│ 점수   최고점수  │
│ 다음 구체 ●      │
├─────────────────┤
│                 │
│   정사각형 보드   │
│                 │
├─────────────────┤
│ 중력 방향 표시 ↓ │
└─────────────────┘
```
- 스와이프는 보드 밖 영역에서도 인식 (손가락이 보드를 가리지 않도록)
- 중력 방향은 화살표 + 보드 테두리 강조로 항상 표시

### 6.2 피드백
- **무게감 (0.8)**: 질량은 구슬 부피에 비례(반지름³)에 가깝게, 큰 구체일수록 중력을 조금 더 세게 받아 묵직하게 떨어진다. 값은 측정으로 정한다
- **표현 (0.7)**: 구체는 광택 있는 입체 구슬, 보드는 입체 프레임. 카메라는 보드를 정면에서 보는 원근(좁은 화각)으로 퍼즐이 한눈에 읽히게 한다
- 중력 전환: 보드가 중력 방향으로 실제로 살짝 기울어지는 연출(약 4°, 0.25초) + 짧은 진동
- 합체: 구체가 부풀며 튀는 스케일 애니메이션
- 상극 소멸: 파편 이펙트, 합체와 확실히 다른 소리
- 연쇄: 연쇄 수 텍스트, 연쇄가 쌓일수록 효과음 음높이 상승

### 6.3 색각 접근성
- 색만으로 구분하지 않도록 구체마다 **문양**을 넣는다 (예: 빨강 ▲, 파랑 ●, 초록 ■)

### 9.1 2048과의 차별화 방향 (2026-09-28 메모)
현재 뼈대(4방향 쏠림 + 같은 것끼리 합체 + 턴마다 생성)는 2048과 가깝다. 상극 소멸(M6)과 함께 아래를 차별화 후보로 검토한다.
- **색상별 물리 성격** (우선 검토): 색마다 질량·반발·마찰을 다르게 한다. 예) 빨강 무겁고 덜 튐 / 파랑 가볍고 잘 구름 / 초록 마찰 커서 잘 멈춤. 색이 합체 조건 외의 의미를 갖게 된다. 수치를 색별 배열로 바꾸면 돼 실험 비용이 가장 낮다
- **군집 효과**: 같은 색끼리 붙은 수에 따라 속도가 빨라지거나 느려진다. 예측 가능성(핵심 재미 3 "연쇄의 계획성")과의 균형 주의
- **실시간 요소**: 일정 시간마다 자동 생성, 또는 굴러가는 중에도 기울이기 허용. 턴제 모드와 별도 모드로 검토
