# 기획서 초안 — 가칭 「그래비티 오브」

> 버전 0.1 · 프로토타입 검증용 기획서
> 모든 수치와 규칙은 가안이며, 플레이테스트 후 조정한다.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 턴제 물리 퍼즐 (합체형) |
| 플랫폼 | 모바일 (세로 화면) |
| 입력 | 상하좌우 스와이프 |
| 레퍼런스 | 2048 (4방향 전체 밀기), 수박게임 (물리 기반 구체 합체·성장), 테트리스 (낙하·공간 관리) |
| 한 줄 소개 | 스와이프로 보드의 중력 방향을 바꿔, 같은 색 구체는 키우고 상극 색 구체는 부딪혀 없애는 퍼즐 |

### 차별점
- **수박게임과 달리** 떨어질 위치가 아니라 **중력 방향 자체**를 조작한다.
- **2048과 달리** 격자가 아닌 물리 공간이라 구체가 실제로 커지며 공간을 차지한다.
- **색 충돌 규칙**으로 "키울 것인가, 없앨 것인가"의 선택이 생긴다.

---

## 2. 핵심 재미 (검증 목표)

프로토타입은 아래 세 가지가 재미있는지만 검증한다.

1. **기울이기의 손맛** — 스와이프 한 번에 보드 전체가 쏟아지는 느낌
2. **성장의 딜레마** — 크게 키울수록 점수는 높지만 공간이 줄어든다
3. **연쇄의 계획성** — 한 번의 스와이프로 합체·소멸이 연달아 터지도록 설계하는 재미

---

## 3. 게임 규칙

### 3.1 보드
- 정사각형 보드 (4방향 중력이 모두 공평하도록)
- 네 면 모두 벽. 구체는 보드 밖으로 나가지 않는다.
- 게임 시작 시 중력 방향은 **아래**, 구체 2개가 배치된 상태로 시작.

### 3.2 입력
| 입력 | 결과 |
|---|---|
| 위/아래/왼쪽/오른쪽 스와이프 | 해당 방향으로 중력 전환 |
| 현재 중력과 같은 방향 스와이프 | 유효 입력으로 인정 (턴 소모, 신규 구체 생성) |
| 처리 중 입력 | 무시 (입력 잠금) |

- 스와이프 판정: 최소 이동 거리 이상 + 주 방향 성분이 우세할 때 인정
- 같은 방향 반복을 허용할지는 **미정 사항**(7장) 참고

### 3.3 중력
- 스와이프한 방향으로 중력이 **유지**된다. (보드를 기울여 둔 상태)
- 다음 스와이프 전까지 중력 방향은 바뀌지 않는다.

### 3.4 구체
- 속성: **색**, **레벨**
- 레벨이 오를수록 반지름이 커진다.
- 반지름 공식(가안): `r = r₀ × 1.25^(레벨-1)`

| 레벨 | 반지름 배율 (가안) | 기본 점수 |
|---|---|---|
| 1 | 1.00 | 2 |
| 2 | 1.25 | 4 |
| 3 | 1.56 | 8 |
| 4 | 1.95 | 16 |
| 5 | 2.44 | 32 |
| 6 | 3.05 | 64 |
| 7 (최대) | 3.81 | 128 |

- 최대 레벨 구체끼리 합체하면 **둘 다 소멸 + 대량 보너스** (보드 청소 수단)

### 3.5 색 충돌 규칙 (프로토타입: 3색)

색: **빨강, 파랑, 초록**

| 충돌 조합 | 결과 |
|---|---|
| 같은 색 + 같은 레벨 | **합체** → 레벨 +1 구체 1개, 두 구체의 중간 지점에 생성 |
| 같은 색 + 다른 레벨 | 아무 일 없음 (밀고 튕김) |
| 빨강 ↔ 파랑 (상극) | **소멸** → 두 구체 모두 제거 |
| 그 외 조합 | 아무 일 없음 |

- 상극 소멸 규칙 대안(검증 후 선택)
  - A안: 레벨 무관 둘 다 소멸 ← **프로토타입 기본값**
  - B안: 레벨이 같을 때만 소멸
  - C안: 큰 쪽이 레벨 차이만큼 남음
- 초록은 상극이 없어 **없애기 어려운 대신 안정적으로 키울 수 있는 색**이 된다.

### 3.6 구체 생성
- 매 턴, 물리가 안정된 뒤 **중력 반대편 벽**에서 신규 구체 1개가 들어온다.
- 생성 위치: 반대편 벽을 따라 무작위 위치 (가안)
- 생성 구체: 레벨 1 (90%), 레벨 2 (10%)
- 색: 3색 균등 확률
- **다음 구체 미리보기** 1개를 화면에 표시

## 4. 턴 처리 순서

```
1. 입력 대기
2. 스와이프 인식 → 입력 잠금
3. 중력 방향 전환
4. 물리 시뮬레이션 진행
5. 충돌 발생 시 색 규칙 판정 → 합체/소멸 처리
6. 연쇄 판정: 합체·소멸 후 다시 4번으로 (안정될 때까지 반복)
7. 안정 판정: 모든 구체 속도가 임계값 이하로 N프레임 유지
8. 반대편 벽에서 신규 구체 생성 → 안정될 때까지 대기
9. 게임오버 판정
10. 입력 잠금 해제 → 1번으로
```

- 7번 안정 판정이 너무 길어지는 경우 대비: **최대 대기 시간**(가안 3초) 초과 시 강제 안정 처리
- 연쇄 한 번마다 짧은 히트스톱·이펙트로 "몇 연쇄인지" 읽히게 한다.

---

## 5. 게임오버 · 점수

### 5.1 게임오버
- 신규 구체 생성 시, 생성 영역이 기존 구체와 겹치면 **게임오버**
- 생성 영역 근처까지 구체가 차오르면 **경고 연출** (벽 가장자리 붉게 점멸)

### 5.2 점수
| 항목 | 점수 |
|---|---|
| 합체 | 생성된 구체의 기본 점수 |
| 상극 소멸 | (두 구체 기본 점수 합) × 0.5 |
| 최대 레벨 합체 | 기본 점수 × 5 |
| 연쇄 배수 | n연쇄째 처리의 점수 × n |

- 표시 지표: 현재 점수, 최고 점수, 최대 연쇄 수

## 6. UI · UX

### 6.1 화면 구성 (세로)
```
┌─────────────────┐
│ 점수   최고점수  │
│ 다음 구체 ●      │
├─────────────────┤
│                 │
│   정사각형 보드   │
│                 │
├─────────────────┤
│ 중력 방향 표시 ↓ │
└─────────────────┘
```
- 스와이프는 보드 밖 영역에서도 인식 (손가락이 보드를 가리지 않도록)
- 중력 방향은 화살표 + 보드 테두리 강조로 항상 표시

### 6.2 피드백
- 중력 전환: 보드가 살짝 기우는 연출 + 짧은 진동
- 합체: 구체가 부풀며 튀는 스케일 애니메이션
- 상극 소멸: 파편 이펙트, 합체와 확실히 다른 소리
- 연쇄: 연쇄 수 텍스트, 연쇄가 쌓일수록 효과음 음높이 상승

### 6.3 색각 접근성
- 색만으로 구분하지 않도록 구체마다 **문양**을 넣는다 (예: 빨강 ▲, 파랑 ●, 초록 ■)

## 8. 프로토타입 범위

### 포함
- 4방향 스와이프 중력 전환
- 3색 + 레벨 1~7 구체
- 합체, 상극 소멸, 연쇄
- 턴 처리 순서 전체, 게임오버, 점수
- 최소한의 피드백 (애니메이션, 연쇄 표시)

### 제외 (다음 단계)
- 사운드 디자인 정식 작업
- 특수 구체 (무지개, 돌, 얼음 등)
- 스테이지·목표 모드
- 실시간 압박 요소 (턴 제한 시간, 주기적 강제 생성)
- 수익화, 메타 성장

## 9. 확장 아이디어 (검증 후)

- **특수 구체**: 무지개(모든 색과 합체), 회색 돌(합체 불가 장애물), 얼음(주변 구체 1턴 고정), 폭탄(주변 소멸)
- **색 추가**: 노랑 추가 후 초록↔노랑 두 번째 상극 쌍
- **색 혼합**: 빨강+파랑=보라 같은 조합 규칙 (규칙 복잡도 주의)
- **모드**: 목표 레벨 달성 스테이지, 제한 턴 내 최고 점수, 실시간 모드
