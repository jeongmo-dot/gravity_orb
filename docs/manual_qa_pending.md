사용자가 실제 창에서 확인할 항목. 자동 검증으로 먼저 병합하고, 사용자 확인 후 체크한다.

- [ ] **기울이기 손맛**: 스와이프하면 보드가 기울며 구슬이 시원하게 쏟아지는가
- [ ] **성장의 딜레마**: 크게 키울수록 공간이 부족해지는 압박이 느껴지는가 (판 후반, 큰 공 잼 포함)
- [ ] **콤보의 쾌감**: 한 번 기울여서 여러 반응이 터질 때 짜릿한가 (#21 이후 확인)
- [ ] **2048과 다르게 느껴지는가**

## 콤보·점수·무게감·충격파 (PR #21, 병합 `5002544`)
- [ ] 같은 턴에 반응이 이어지면 `COMBO x1 → x2 → x4`로 오르고, 다음 스와이프에 사라진다
- [ ] 판이 30% 이상 차면 `DANGER x…`가 보이고, 점수가 시원하게 커진다 (12판 측정 중앙값 약 15,000점)
- [ ] **큰 공이 확실히 무겁게 느껴진다** — 작은 공에 잘 안 밀리고, 더 빨리 떨어진다
- [ ] **합체할 때 주변 공이 "펑" 밀려나는 충격파**가 느껴지고, L7 청소는 판 전체를 흔든다. 너무 과하지 않다
- [ ] (관찰) 후반에 더미가 한 덩어리로 굳는 현상이 여전한지 — 측정상 충격파로는 거의 안 풀림 → #22

## 3D 화면·조작 (PR #20)

- [ ] 보드 전체와 HUD가 세로 화면에 잘리지 않는다 (기울기 순간 포함)

- [ ] 공이 벽에 박히거나 서로 깊이 파고드는 모습이 눈에 띄지 않는다 (측정상 합체 직후 짧게 겹칠 수 있음)

## 규칙·흐름 (PR #8·#10·#12·#15·#16 — 3D 빌드에서)
- [ ] 스와이프 후 1.5초 안에 다음 입력, 굴러가는 중 입력이 어색하지 않다
- [ ] 입력 대기 중에도 같은 색·같은 크기가 닿으면 합체한다
- [ ] 시작 규칙 `Rule: B` — 같은 레벨 빨강·파랑만 소멸, 초록·노랑은 소멸 없음. F2로 A/B/C 전환
- [ ] NEXT 2개, 스와이프하면 둘 다 들어온다. F3으로 생성 수 1/2/3
- [ ] 생성 벽이 막히면 새 공이 입구에서 대기하다 자리가 나면 들어온다
- [ ] 경고 방향으로 기울여 끝내 못 들어오면 GAME OVER 패널, RESTART·R키
- [ ] (관찰) 한 판 길이 — 측정상 약 245턴(6분 안팎)이 적당한지
- [ ] (관찰) 판이 차오르는 속도
