## 색별 합체 효과·상극 폐지 (PR #25, 병합 `d73468a`)

- [ ] 효과 세기가 과하거나 약하지 않은가 (빨강 ×1.5, 파랑 ×0.8, 초록 150px/s, 노랑 ×1.0)
- [ ] 빨강·파랑 같은 레벨이 닿아도 소멸하지 않고, 디버그에 `Rule: off`
- [ ] (관찰) 한 판 길이 — 측정상 약 **135턴**으로 #23 기준 258턴의 절반. 짧게 느껴지는가

## 순차 연쇄·콤보 표시 (PR #22·#24, 병합 `f7ecd05`·`e756a6e`)
